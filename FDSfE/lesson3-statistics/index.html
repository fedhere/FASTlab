The Poisson Distribution¶

The Poisson distribution is defined on a discrete support: the natural numbers starting at 0.

The Poisson distribution is defined by one parameter, λ\lambdaλ, the mean of the distribution.

Use scipy.stats.poisson to plot the probability mass function (PMF) of a Poisson distribution.

support = np.arange(30)
mu_poisson = 12
pmf_poisson = stats.poisson.pmf(support, 12)

fig, ax = plt.subplots(figsize=(10, 4))
ax.bar(support, stats.poisson.pmf(support, 3), label="Poisson, mean = 3")
ax.bar(support, pmf_poisson, label="Poisson, mean = 12", alpha=0.75)

ax.set_xticks(support)
ax.set_xlabel("Support, k")
ax.set_ylabel("Probability Mass Function")

ax.legend()
fig.show()

The Gaussian (Normal) Distribution¶

The Gaussian distribution is defined on a continuous support: all real numbers.

The Gaussian distribution is defined by two parameters: μ\muμ, the mean of the distribution and σ\sigmaσ, the standard deviation of the distribution.

Use scipy.stats.norm to plot the probability density function (PDF) of a Gaussian (normal) distribution.

The Moments of the Gaussian Distribution¶

Use scipy.stats.moment to calculate and plot the second, third and fourth central moments of a Gaussian distribution.

support = np.linspace(-10, 10, num=1001)
pdf1 = stats.norm.pdf(support, loc=0, scale=1)

stats.norm.stats(loc=-1, scale=2, moments="mvsk")

The Quantiles of the Gaussian Distribution¶

Plot a Guassian PDF, and plot vertical lines at N(μ±nσ)\mathcal{N}(\mu \pm n \sigma)N(μ±nσ) for n=1,2,3,4,5n = 1, 2, 3, 4, 5n=1,2,3,4,5.

Integrate the Gaussian PDF between x=μ−nσx = \mu - n \sigmax=μ−nσ and x=μ+nσx = \mu + n \sigmax=μ+nσ. What percentage of the PDF does this integral account for, for each n?

Use scipy.stats.quantile to calculate these quantiles.

support = np.linspace(-100, 100, num=100_001)

mu = 0
sd = 1
pdf = stats.norm.pdf(support, loc=mu, scale=sd)

fig, ax = plt.subplots(figsize=(5, 3))
ax.plot(support, pdf)

colors = [
    "blue", "green", "orange", "yellow", "red"
]

integrals = []
for i, n in enumerate(range(1, 5+1)):
    bounds = (mu - n * sd, mu + n * sd)
    ind = np.where(np.logical_and(support >= bounds[0], support <= bounds[1]))[0]
    integrals.append(np.trapezoid(pdf[ind], x=support[ind]))

    ax.axvline(x=bounds[0], color="black", ls=":")
    ax.axvline(x=bounds[1], color="black", ls=":")

    ind_neg = np.where(np.logical_and(support >= mu - n * sd, support <= mu - (n-1) * sd))[0]
    ind_pos = np.where(np.logical_and(support >= mu + (n-1) * sd, support <= mu + n * sd))[0]

    

    ax.fill_between(support[ind_neg], y1=pdf[ind_neg], color=colors[i], alpha=0.5)
    ax.fill_between(support[ind_pos], y1=pdf[ind_pos], color=colors[i], alpha=0.5)

ax.set_xlim((-6, 6))
ax.set_ylim((0, None))

fig.show()
